MCP

Model Context Protocol

Ye Kya Hai?

MCP AI ko external apps se connect karta hai jaise GitHub, Figma, Notion aur Google Drive.

Example

Claude → MCP → GitHub → Repo Create

Purpose

AI ko real world kaam karwana.

Galtiyan

  • ❌ API keys expose mat karo
  • ❌ Wrong permissions mat do
  • ❌ Too many tools ek sath use mat karo

Skills

AI Trained Behavior

Ye Kya Hai?

Skills AI ko specific kaam properly sikhati hain taake har baar same prompt repeat na karna pade.

Example

Purpose

Consistency aur automation.

Galtiyan
